How it works

Add the domain you already own (for example mystore.com) and we will make it your storefront automatically. Our system periodically checks your DNS, issues a free SSL certificate, and activates the domain — no technical setup needed by you. You are looking for these steps:

{% if primary_domain and primary_domain.status == 'active' %}
{{ primary_domain.domain }} is now live — visitors will see your store when they open https://{{ primary_domain.domain }}. The platform address stays in the address bar.
{% endif %}
